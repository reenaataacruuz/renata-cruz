# Renata Cruz — Portfolio em website

Este é o meu portfólio em formato de website profissional, sou Analista de QA (Manual & Automação). E apresento aqui minha trajetória, habilidades técnicas, experiências profissionais e projetos realizados.



## Demonstração Visual & Características

Desenvolvi com foco em uma experiência fluida, limpa e moderna, e que ao mesmo tempo eu pudesse usar para estudar o lado da "estrutura" da automação.

### Principais funcionalidades:
- **Design responsivo:** Adaptado para dispositivos móveis, tablets e desktop.
- **Tema claro & escuro (Dark/Light Mode):** Alternância de tema que é informada pelo usuário e lembrada em visitas futuras.
- **Portfólio de projetos:** Exposição direta de repositórios reais no GitHub focados em testes (Cypress, APIs, CI/CD).
- **Linha do tempo de experiência:** Histórico profissional com breve descrição.
- **Desempenho otimizado:** Sem dependência de frameworks, resultando em um carregamento rápido.



## Tecnologias utilizadas

O projeto foi construído utilizando tecnologias web puras para exibir o meu portfolio, então é limpo e sem muita utilização de frameworks.

- **HTML5:** Estruturação semântica de todo o conteúdo do site.
- **CSS3:** Estilização moderna baseada em variáveis CSS para temas dinâmicos, Flexbox/Grid para layouts responsivos e transições suaves.
- **JavaScript (Vanilla JS):** Lógica simples para controle do menu hambúrguer em dispositivos móveis e persistência da preferência de tema claro/escuro via `localStorage`.
- **Google Fonts:** Tipografia utilizando a fonte *DM Sans* para uma leitura moderna e confortável.
- **Iconografia:** Ícones inline SVG otimizados para um melhor carregamento.
